# 深度学习分割管线(实验性新算法)

独立于现有启发式检测器(`ImageProcessor.swift`,0.979 mean IoU)。目标:用一个
"看得懂照片vs黑边"的语义分割模型,突破启发式方法在暗帧/弱 gutter 上的固有上限。

## 为什么需要它

现有启发式(投影、gutter 分类、网格一致性、梯度)已到 ~90 分。剩余长尾误差全部
落在**像素信息本身模糊**处:暗帧(gutter 与暗内容像素上不可分)、弱 gutter、真实
不规则。已验证两个纯像素新机制(列对齐、梯度峰值)都**退化**——因为它们和现有方法
一样没有语义理解。只有学到"这块是照片、那块是黑边"语义的模型能突破。

## 管线

1. `prepare_data.py` — 把 app 保存的裁切框(`.imgslicer-edits.json`)转成
   (图, 掩码) 分割数据集。manual 修正=真值,auto=伪标注。→ `data/`
2. `train.py` — 轻量 U-Net,256×256 patch + 强增强(应对少数据),manual 图留作
   验证。→ `unet.pt`
3. `export_coreml.py` (待补) — 转 Core ML,供 Swift 用 Vision 框架推理。
4. Swift 集成 (待补) — 作为一个新的 detection stage/candidate,与现有并存,
   benchmark 选优。**不改动现有算法**。

## ⚠️ 数据是当前的硬瓶颈

深度学习的上限由数据量决定,这不是调参能改变的:

- **现在只有 8 张真实手工标注** + 37 张伪标注(现有算法输出)。
- 用伪标注训练 = 蒸馏现有算法 = **天花板就是 90 分**,学不到超越。
- 8 张真标注 **远不足以**让模型学到暗帧的语义并泛化。

**结论:当前数据训不出超越 90 分的模型。** 管线搭好是为了未来——当积累够数据时
直接能训。

### 需要多少数据

经验估计:**200–500 张手工修正的 contact sheet** 才能让分割模型稳定超越启发式
(尤其覆盖足够多的暗帧/弱 gutter 样本)。

### 怎么积累(零额外成本)

你日常用 app 处理胶片、手工微调框时,每次修正都自动存进 `.imgslicer-edits.json`。
用一段时间自然攒够,`prepare_data.py` 就能把它们全部转成训练数据。到量后我用这个
管线训练 + 导出 + 集成。
